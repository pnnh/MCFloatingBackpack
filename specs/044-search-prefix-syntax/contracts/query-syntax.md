# 契约：查询语法（044 版，含 042 的基础语法）

玩家在搜索框里输入的文字如何解释。042 的写法（词、空格、`|`、`-`、引号）**完全不变**；044 加三个前缀。

## 基础语法（042，不变）

| 写法 | 含义 | 例子 |
|---|---|---|
| 词 | 物品的"可搜索文字"里含有该词（子串，不区分大小写） | `pick` |
| 空格 | 并且；词序无关 | `iron pick` |
| `a\|b` | 或 | `iron\|gold` |
| `-a`（备选开头） | 排除 | `-planks` |
| `"a b"` | 整段（引号内的空格、`\|`、`-`、`@`、`#` 都是普通字符；引号本身不算文字；没闭合则到末尾） | `"oak log"` |
| 空的项/备选 | 忽略 | `iron\|`、单独的 `-` |
| 整条没有有效项 | 空查询：不过滤、不高亮 | |
| 最长 | 100 个字符（码点），超出的输入被忽略 | |

**可搜索文字**（词的匹配范围）：当前语言显示名（含改过名的）、注册名路径、（043）提供者给的词。

## 前缀（044 新增）

前缀只在**备选的开头**（可以在 `-` 之后）、**不在引号内**时生效；其它位置的 `@`、`#` 是普通字符。

| 写法 | 含义 | 例子 |
|---|---|---|
| `@文字` | 物品属于某模组：注册名的**命名空间**或所属模组的**显示名**含该文字（子串、不区分大小写） | `@minecraft`、`@sophisticated`、`@mekanism ingot` |
| `@"含 空格 的文字"` | 同上，`@` 之后的引号是整段 | `@"sophisticated backpacks"` |
| `#文字`（不含 `:`） | 物品带某标签：**物品标签**（含 `minecraft:`、`c:`、别的模组的）的 id 的**路径部分**含该文字；或**背包标签**的 id 或当前语言显示名含该文字 | `#logs`、`#ingots`、`#trash`、`#垃圾` |
| `#文字`（含 `:`） | 物品标签的**完整 id 以该文字开头**；背包标签不参与 | `#c:ingots`、`#minecraft:logs`、`#c:ingots/iron` |
| `-@文字`、`-#文字` | 排除 | `-#planks` |
| 单独的 `@`、`#`、`-@`、`-#` | 空备选，忽略 | |

- 前缀项与基础语法自由组合：`@minecraft #logs`（并且）、`#logs\|#planks`（或）、`@mekanism -ingot`。
- **提供者的词（043）不参与 `@`、`#`。**
- 物品没有任何标签：`#任何` 不成立；`-#任何` 为真（不排除它）。
- `#` 的三类标签取并集：任一类命中即命中。

## 指令（044 新增）

整条查询**去掉前导空白后**以 `/` 开头：第一个"词"（到第一个空白，转小写）是指令；**其它位置的 `/`（含引号内）是普通字符**。

| 输入 | 效果 |
|---|---|
| `/hidden` | 主区域不显示物品格子，改为列出"哪些类别有隐藏物品、各几格"（037 的数据与说法）与"把对应的分类扩展放回工具区即可取回"；没有隐藏物品时显示"没有隐藏的物品"（有隐藏物品但指令后的词把类别都滤掉时显示"没有符合的隐藏类别"）；框内计数 = 隐藏格总数；工具区无命中框 |
| `/hidden 词…` | 指令之后的文字**只过滤类别行**：每个普通词要在该类别的当前语言显示名或 id 里出现（并且、`\|`、`-`、引号规则同上）；`@`、`#` 备选对类别行**不成立** |
| `/`、`/h`、`/foo`、`/hiddenx` | **未知指令**：无结果；搜索框悬停提示"未知指令：<输入>（可用：/hidden）" |
| `a /hidden`、`"/hidden"`、`a/b` | 没有指令；`/` 是普通字符 |

**已知限制**：隐藏物品本身不在客户端（只同步摘要），所以 `/hidden` 不能按物品名过滤，也不显示物品。

## 解析用例（单元测试要覆盖）

| 输入 | 结果 |
|---|---|
| `@minecraft` | 项 [[MOD +minecraft]] |
| `#logs` | [[TAG +logs]] |
| `-@mod` / `-#tag` | [[MOD -mod]] / [[TAG -tag]] |
| `@`、`#`、`-@`、`-#`、`@ `、`# ` | 空查询 |
| `@ mekanism` | [[WORD mekanism]]（`@` 空，丢弃） |
| `@"a b"` | [[MOD +a b]] |
| `"@x"`、`a@b`、`a#b`、`ab@` | 词：`@x`、`a@b`、`a#b`、`ab@` |
| `@a\|#b` | [[MOD a, TAG b]] |
| `@a\|-#b` | [[MOD a, TAG -b]] |
| `@Minecraft #LOGS` | [[MOD minecraft],[TAG logs]]（已转小写） |
| `@minecraft #logs oak` | [[MOD minecraft],[TAG logs],[WORD oak]] |
| `/hidden`、`  /hidden`、`/HIDDEN`、`/hidden ` | 指令 HIDDEN，terms 空 |
| `/hidden fish` | HIDDEN，[[WORD fish]] |
| `/hidden @x` | HIDDEN，[[MOD x]] |
| `/`、`/h`、`/foo`、`/hiddenx`、`/hidden2` | 指令 UNKNOWN（raw 为输入的指令词） |
| `a /hidden`、`"/hidden"`、`a/b`、`-/hidden` | 无指令；词里含 `/` |
| 042 的全部用例 | 不变 |

## 匹配用例（单元测试要覆盖）

| 物品 | 查询 | 结果 |
|---|---|---|
| 命名空间 `minecraft` | `@minecraft`、`@mine`、`@CRAFT` | 命中 |
| 命名空间 `sophisticatedbackpacks`，显示名 `Sophisticated Backpacks` | `@sophisticated`、`@"sophisticated backpacks"`、`@pack` | 命中 |
| 同上 | `@minecraft` | 不命中 |
| 带 `minecraft:logs`、`minecraft:oak_logs` | `#logs`、`#oak_logs`、`#minecraft:logs`、`#minecraft:` | 命中 |
| 同上 | `#c:logs` | 不命中 |
| 带 `c:ingots/iron` | `#ingots`、`#iron`、`#c:ingots`、`#c:ingots/iron`、`#c:` | 命中；`#ingots/iron` 命中（路径含）；`#minecraft:ingots` 不命中 |
| 背包标签 `trash`（显示名"垃圾"） | `#trash`、`#垃圾`、`#tra` | 命中；`#c:trash` 不命中 |
| 自定义背包标签 `my tools` | `#my`（`#"my tools"`） | 命中 |
| 同时有物品标签与背包标签 | 任一类命中 | 命中（并集） |
| 没有任何标签 | `#x` / `-#x` | 不成立 / 为真 |
| 类别行（`/hidden`）名为 "Fishing"，id `fishing` | `fish`、`-fish`、`@x`、`#x`、`-@x` | 命中；不命中；不命中；不命中；命中 |
