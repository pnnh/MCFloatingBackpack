# Quickstart: 013 面板内拖动均分与拖动收集 验收

## 构建与自动化检查

```bash
./gradlew compileJava test
```

覆盖：`PanelCursorLogic`（均分、右键、收集、双击收集，用假栈）、`PanelDragGesture`（状态机）、请求校验。**不能证明手势在游戏里可用**——宪法 V 条要求下面的客户端会话验证。

## 客户端会话验证（必须实际执行）

```bash
./gradlew runClient
```

创造模式，取出皮革背包，按 B 打开面板。面板里先放一些圆石（60、30、20 个等零散堆叠）、几种不同的方块。macOS 上"Ctrl"指 **Command 键**（本功能不使用 Ctrl，只在"让路"时用到）。

### 一、拖动均分（US1）

1. 面板里拿起一组 60 个圆石，按住左键从一个空格滑过另外三个空格再松开 → 每格 15 个，光标变空。（SC-001）
2. 拿起 10 个，滑过三个空格 → 每格 3 个，光标剩 1 个。（SC-002）
3. 拿起 64 个，滑过一个已有 60 个圆石的格子和两个空格 → 已有 60 个的格子只多 4 个，其余按均分结果，多出的留在光标。
4. 拖动过程中预览：被滑过的格子显示将放入的数量，光标显示将剩余数量；松开前物品不变；只滑过一个格子时不显示预览。（FR-005）
5. 只滑过一个格子就松开 → 与普通点击一样放下。（FR-003）
6. 滑过不同种物品的格子和已满的格子 → 前者被忽略，后者占一个份额但放不进东西（与原版一致）。
7. 同一个格子来回滑过 → 只算一次。（FR-004）
8. **HUD（没有界面）与打开着物品栏（E）各做一遍**，结果相同。（SC-006）

### 二、右键拖动（US3）

9. 拿起 10 个，按住右键滑过五个空格 → 每格 1 个，光标剩 5 个。（FR-015）

### 三、拖动收集（US2）

10. 面板里有三格圆石（20、30、40）：在第一格按下左键拿起 20 个，不松手滑过第二、第三格 → 光标 20 → 50 → 64，第三格剩 26。（SC-004）
11. 滑过不同种物品或空格 → 被忽略。
12. 光标已满后继续滑过 → 不再收集。
13. 收集到一半松开 → 光标上保持部分堆叠，再点击别的格子可以一次性放下。
14. HUD 与打开界面各做一遍。

### 四、双击收集（US4）

15. 光标拿着 10 个圆石，面板里有 20、30、64 的三格圆石：左键双击其中一个空格（或已拿起的那格）→ 先收未满的（20、30），再从满的补到 64。（FR-016）

### 五、不能被影响的（US5）

16. 拿着物品在面板里**单击**一个格子 → 放下/交换，与以前一致（只是松开时才生效）。
17. 光标为空时单击有物品的格子 → 立即拿起整组；右键单击 → 拿起一半。
18. 右键点击放一个到空格 → 与以前一致。
19. 按着 Command 点击或拖动面板格子 → 仍是 011/012 的快速转移，不触发本功能。（FR-011）
20. 按着 Shift → 不触发本功能。
21. 玩家物品栏、箱子、精妙背包、旅行者背包**自己的格子**里的拖动 → 与改动前完全一致（用 `runClientCompat` 看精妙背包和旅行者背包）。（FR-018）
22. 011/012 的 quickstart 重跑一遍，结果相同。

### 六、边界与守恒（SC-003）

23. 拖动分配中途按 E/ESC 关闭界面，或隐藏面板 → 拖动均分作废，物品不变；拖动收集已收的保留。（FR-014）
24. 做 50 次以上拖动均分与拖动收集（含已满、不同种、数量不足），前后相关物品总数应完全相等。

### 七、平台

- 本机验证 macOS。Windows/Linux 无法验证，登记为未验证。
