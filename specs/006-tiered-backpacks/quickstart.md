# Quickstart: 006 分级背包验收

## 构建

```bash
./gradlew compileJava test
./gradlew runClient
```

开发客户端仍默认带 JEI。关闭：`./gradlew runClient -PnoJei`。

设计细节见 [data-model.md](data-model.md) 与 [contracts/tiered-backpack.md](contracts/tiered-backpack.md)。

## 手工检查

### 五档格子

1. 创造分类取出皮革、铁、金、钻石、下界合金各一只。
2. 在游戏画面（不先按 E）分别拿在主手，按 **B**。
3. 行数应为 4、6、8、10、12，每行 9 格。
4. 无背包时按 **B** 有提示且不开面板。
5. **ESC** 或再按 **B** 关闭；暂停菜单上看不见面板。

### 升级保留物品

1. 皮革背包放入至少 5 种不同物品（含一个堆叠）。
2. 锻造台：模板槽留空，基底放皮革背包，附加放 **铁块**。
3. 取出铁背包。原物品都在，并多出空行。皮革背包与铁块各少 1。
4. 同样路径：铁 + **金块** → 金；金 + **钻石** → 钻石；钻石 + **下界合金锭** → 下界合金。
5. 模板槽放入东西，或基底与材料不配套：没有结果。
6. 没有把高等级变回低等级的配方。

### 外观

1. 快捷栏并排五只背包：图标都是背包，五色可分，没有纯色方块。
2. 手持时能看出包身而不是纸片或立方体。
3. 潜行装备到胸甲，F5：背部是对应配色的背包（肩带、盖、包身），不是立方体，也不是一套皮甲/铁甲。**【009 修订】** 现在背部是无肩带的包身、顶盖与口袋；外观的完整验证清单见 [009 quickstart.md](../009-sculpted-mesh-backpack-models/quickstart.md)。
4. 五张物品贴图宽和高都不小于 32。**【009 修订】** 下限仍成立，当前为 1024×1024。

### 小窗口

1. 把 GUI 比例调高或缩小窗口，打开下界合金背包（12 行）。
2. 面板内滚轮能滚到第一行和最后一行，每一格都能点。

### 回归

1. 打开原版物品栏，面板与玩家物品栏互拖，数量不变。
2. 把装了东西的金背包丢出再捡起，内容仍在。
3. 主手皮革、背包格里有下界合金时，按 B 打开的是皮革（36 格）。
