# 交付记录：联合背包 · "全部"标签（066）

2026-11-24。**未提交**。自动测试：268 个测试类 / 2017 项 / 0 失败（含下面"第一轮真机反馈"之后的改动），`./gradlew build -PcleanRuntime -PnoJei` 通过（065 之后是 259 / 1974）。

## 做了什么

- **"全部"标签**：标签栏最前，U 打开联合面板默认落在它上面；所有成员背包的主区域按顺序拼成一个平铺网格（每只背包在客户端从新的一行开始，块末尾是填充格）。
- **服务端寻址**：平铺号（成员主区域长度的前缀和）+ **epoch**；点击、拖动分摊/收集、快速转移（两个方向）、容器取入、网络终端取出、合并光标都有"全部"分支；成员各自 `saveInventory`，同一请求内每成员最多解码一次。
- **内存光标**：会话里的 `AllState.cursor`，请求内用 `CursorLoan` 借给被操作的成员、保存前取回并清空，成员存档里没有它；`CombinedSessions.flush` 在关闭、B 键、切标签、成员/大小变化、`enabled=false`、下线、停服前调用（成员 → 物品栏 → 脚下）。
- **同步**：`CombinedMemberSyncPayload`（每成员一包，只含主区域 + 行 + 标签 + 光标）、`CombinedCellUpdatePayload`（单格 + 光标）；每秒钩子对每个成员先比"内容对象引用"，不同再比主区域/行/标签，变了才推。
- **客户端**：`ClientCombinedView` 把拼好的网格装进 `ClientBackpackView` 单例（渲染/拖动/选择几乎不用改）；格子按成员淡染、悬停提示末尾"来自 ■编号（位置）"、悬停格点亮对应标签；面板标题栏上的搜索照常用，整理按钮在"全部"里只改显示。
- **取消联合标题栏**（用户 2026-11-24 的决定）：标签栏直接贴面板上沿，`BARS_H` 30 → 16；"+n"未连接徽标画在"全部"标签里，档位与计数在它的悬停提示里。
- **协议 23 → 24**；`DataRevision` 仍 6；不新增贴图、依赖、mixin、反射。

## 顺手修的 065 隐患

自动拾取是自己直接发 `BackpackSlotUpdatePayload` 的；管子与 `saveInventory` 的布局变化会发整包同步。联合面板停在"不是 B 激活的那只"的标签时，客户端会把这些更新套到当前显示的背包上，**画面错位**（服务端数据没错）。现在 `BackpackNetwork.sendSlotUpdate/sendFullSync/sendPickupUpdate` 认会话：具体标签只在更新的是目标背包时才发，"全部"翻成平铺号。**该修复本身没有在游戏里单独复现与验证**（见下"没验证到的"）。

## 与规格/plan 的出入

1. **标签栏没有联合标题栏**（用户决定）：规格与 plan 已同步；"+n"徽标在"全部"标签里，不在标签栏右端。
2. **整理的显示顺序只按物品的注册名顺序**（`ItemSortOrder`），**没有"分类行优先"**：聚合显示里没有对应物，行里的格子照样按物品排。规格 FR-021 写了"分类行优先"，实际不是；需要的话再议。
3. **"全部"里 `/hidden` 不汇总各成员的隐藏行**（显示空）；规格没要求汇总，只是搜索语法里的这一条在"全部"里没有内容。
4. 整理的排列表在"离开再回来"时**按新数据重算**（保留的是"已整理"这个模式，不是上一次的具体排列）；关闭联合面板后回到默认视图。规格 FR-022 写"保留排列表"，实际保留模式，效果一致（物品没变时顺序一样）。
5. 悬停提示：光标上拿着东西时，格子悬停只显示"来自"一行（不显示物品本身的提示）。
6. `CombinedSelectPayload.OPEN`（U 键）打开"全部"；065 的"偏好 B 的那只"逻辑已去掉。

## 第一轮真机反馈之后的调整（2026-11-24）

用户看了真机截图，提了四点，都已改并在容器里看过截图：

1. **"全部"里网格撑满整个面板**：左右区和底部功能区不再留空（原先画成宽边框）；新增 `PanelLayout.ofFull`：主区域 = 面板里面整块（列数 +2、行数 +1），左右/底部区不存在（无格子、无命中）；面板自己的大小不变。显示映射、滚动、点击翻译都按新的列数走（`FloatingPanelState.mainCols()/mainRows()`）。单元测试 `PanelLayoutFullTest`。
2. **标签栏与面板成一个整体**：标签栏不再有自己的黑框和斜面，用面板同样的底色与明暗边；面板外轮廓的黑线包住"标签栏 + 面板"整体，原来夹在中间的那条黑线被盖掉（只剩面板顶边的一条浅色高光线）。被选中和未选中标签自己的黑色小边框没改。**若你要的是连外轮廓都不要黑线，或者标签自己的黑框也不要，再说。**
3. **"按 B 会打开这一只"改成"主背包：自动拾取和移动工具作用于这一只"**（中英），"移动工具只对按 B 打开的背包生效"改成"……只对主背包生效"；README 中英同步，不再写具体按键。
4. **"全部"里的扩展行画得和单个背包一样**：行的底色、行首小方块、空格里对应扩展物品的淡淡缩略图；悬停扩展行格子有行的提示。每只背包用自己的行布局（各自的 `RowView`）；**整理后或搜索时只画底色**（此时行的格子不在一起，边线与角标没有意义）。容器里用食物扩展验证：橙色底、小方块、空格里的缩略图都在，滚动与换行（块内 11 列）正确。

## 第二轮真机反馈之后的调整（2026-11-24）

1. **格子首尾相连**：不再"每只背包从新的一行开始"。`AllGrid.displayMap` 现在就是按顺序的平铺号（无空位），手动调大小也不会在中间出现空洞，只有最后一行的尾部可能不满。扩展行的底色与边线按**显示出来的相邻格**比较（`drawRowDecorAll`，上方/左侧格属于另一组才画线），所以一行从行中间开始也画得对；整理或搜索时只画底色。
2. **B 与 U 交替**：联合面板开着时按 B，显示的是普通背包面板（服务端结束联合会话），再按 B 关闭；普通面板开着时按 U 开联合面板，再按 U 关闭。
3. **标题栏右侧按钮放大并居中**：按钮 10 → 12 像素，在 17 像素高的标题栏里上沿留 3（`TitleBarLayout.BUTTON_TOP`），放大镜、整理、快照图标的画法按 12 像素重画；搜索框的位置、清除按钮、文字行与光标随按钮高度居中（字体大小不变，行高 9 在 12 高的框里居中）。`TitleBarLayoutTest` 的数值随之更新。
