# 契约：查询语法（042 基础语法）

玩家在搜索框里输入的文字如何解释。044 会在此基础上加前缀（`@`、`#`、开头的 `/`），本 feature 把它们当普通字符。

| 写法 | 含义 | 例子 |
|---|---|---|
| 词 | 物品的"可搜索文字"里含有该词（子串，不区分大小写） | `pick` → Diamond Pickaxe、Iron Pickaxe |
| 空格 | 并且；词序无关 | `iron pick` → 同时含 iron 与 pick |
| `a\|b` | 或：含 a 或含 b | `iron\|gold` |
| `-a`（项首） | 排除：名字不含 a | `-planks` |
| `"a b"` | 整段：含连续的 `a b`（引号里的空格、`\|`、`-` 都是普通字符） | `"oak log"`、`-"oak log"` |
| 引号没闭合 | 从开引号到末尾按整段 | `"oak lo` |
| 连续空格、`iron\|`、单独的 `-` | 空的项/备选，忽略 | |
| 整条没有有效项 | 等同空查询：不过滤、不高亮 | |

**可搜索文字**：物品当前语言的显示名（含改过名的物品）、物品注册名的路径部分（如 `diamond_pickaxe`）。

**备选里的排除**：`iron|-gold` 按字面是"含 iron，或不含 gold"（备选之间是"或"；排除备选成立 = 没有任何可搜索文字含它）。这是规格 FR-020 的字面定义，不另作解释；常用的是整项排除 `-gold`。

**限制**：整条查询最多 100 个字符（码点）；超出的输入被忽略。
