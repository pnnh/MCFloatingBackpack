# Quickstart: 标签总览验收步骤

按宪法 V，下面的玩家可见行为都要在客户端会话里逐项验证；单元测试和编译不能代替。未验证的项在 tasks/DELIVERY 里保持"未验证"。

## 准备

```bash
pgrep -f "fml.modFolders=mcfloatingbackpack" || echo "没有游戏在跑"   # 有就不要启动第二个，也不要杀用户的游戏
./gradlew test
./gradlew runClient
```

进创造模式世界。拿：浮动背包 ×2（A、B，下界合金背包更方便）、标签管理器（放进 A 的下方功能区）、自动拾取（可选）、垃圾桶（可选）；再准备圆石、橡木原木、钻石、一个潜影盒（受保护物品）、各种杂物。

## A. 入口与切换

- **Q1** 展开标签面板：状态行右端有菜单图标（三条横线），悬停提示"标签总览"；选区视图一切照旧（Shift 选格子、增删标签）。
- **Q2** 点图标 → 进入总览列表；图标高亮、悬停提示变成"返回选区"；再点 → 回到选区视图，之前 Shift 选中的格子**还在**。
- **Q3** 反复切换 10 次，选区不变。
- **Q4** 在总览里收起面板（再次左键标签管理器）再展开：回到收起前的视图、滚动与筛选。
- **Q5** 拿走标签管理器 / 关闭浮动面板 / 退出世界再进：回到选区视图，筛选与明细都清空；按 B 重新打开面板同样回到选区视图。
- **Q6** 同时展开自动拾取的黑名单页（024）：标签面板收起，反之亦然（既有互斥）。

## B. 列表页

- **Q7** 给圆石打 `stone`、给橡木原木打 `wood` 和 `food`、给钻石打 `treasure`（自定义）：总览列出这三行，名称/图标/标签数量（1、2、1）正确；悬停列出完整标签（"石头""木材"等按语言显示）。
- **Q8** 把圆石、钻石从背包里拿走：总览**仍然有**这些行。
- **Q9** 换另一只没打过标签的背包 B：总览显示"还没有给任何物品打过标签"。
- **Q10** 给 40 种以上物品各打一个标签：列表可滚动，滚轮一次一行，滚到头不再动；滚轮不穿透到下面的界面。
- **Q11** 切换游戏语言（中↔英）：列表按新的显示名重排；预设标签的显示名随语言变。

## C. 按标签筛选

- **Q12** 点筛选行：下拉列出预设标签和已用过的标签（如 `treasure`）；输入 `tr` 模糊匹配出"垃圾/trash/treasure"等；选 `trash` → 只剩带 `trash` 的物品；筛选行显示 `trash` 与 `×`。
- **Q13** 点 `×` 清除筛选，恢复全部；筛选一个没有物品带的标签 → "没有符合的物品"，仍能清除。
- **Q14** 筛选框有焦点时打字：`e`、`t`、数字、Delete 都不触发别的快捷键；ESC 取消编辑但不清除已有筛选；没有焦点时不拦截键盘（按 B 能关面板）。
- **Q15** 输入大写字母、空格：被过滤掉（与 018 添加框相同）。

## D. 明细页

- **Q16** 点圆石那一行 → 进入明细：返回按钮、图标、名称、标签块、加号；点返回回到列表，滚动与筛选保持。
- **Q17** 点标签出现删除标记，点删除移除；加号 → 文本框 + 下拉（预设 + 已用标签，不含该分类已有的），Enter 添加；ESC 取消。
- **Q18** 圆石已不在背包里：增、删标签照常成功。
- **Q19** 给同一分类加到 10 个标签：加号变灰、悬停提示已满；再尝试（比如用别的方式发请求）被服务端拒绝，标签数不变。
- **Q20** 给受保护物品（潜影盒）加 `trash`：下拉里"垃圾"变灰、悬停提示受保护、添加被拒绝；加别的标签成功。
- **Q21** 删掉某物品的**最后一个**标签：明细页自动回到列表，该行消失。
- **Q22**（可选，需要移除一个模组后进旧存档）已不在游戏里的物品：列表里显示原始注册 id 和占位图标；明细页加号灰、悬停提示"这个物品已不在游戏里，只能删除标签"；仍可删除标签、清空。

## E. 清空（二次确认）

- **Q23** 点某行"清空"：该行变成"确认清空？"，**什么都没清**；点别处 / 滚动 / 切换视图 / 等 3 秒 / 点另一行的"清空"：确认状态取消（后者取代），数据不变。
- **Q24** 在确认状态再点一次：该分类标签全部移除，行消失，其它行不变。
- **Q25** 清空后在选区视图选中该物品（若在背包）：共同标签为"无"；022 的"一键倾倒"不再倾倒它（若曾有 `trash`）；024 的黑名单不再命中它。
- **Q26** 对受保护物品（潜影盒）的分类清空：成功。

## F. 服务端权威与回归

- **Q27** 拿走标签管理器后（面板收起）无法再操作；若在总览时标签管理器被拿走，面板收起并回到选区视图。
- **Q28** 非法请求（没有标签管理器、没有标签的分类上加标签、非法标签、超过 10 个、非法注册 id、对已不在游戏里的物品加标签）全部零变化——**靠 `TagOverviewRulesTest` / `TagOverviewRequestTest` 的单元测试；游戏里只验证"客户端没有提供这样的入口"**。
- **Q29** 退出重进、关闭面板、锻造台升级背包、换背包：总览里的标签与之前一致且两只背包互不共享；旧存档正常。
- **Q30** 回归 011～024 的验证项（选区视图增删标签、022 的倾倒与 Delete 键与保护提示、024 的黑名单与拾取与互斥、垃圾桶、Ctrl 转移、拖动、缩放、滚动、020 兼容开关、宿主界面）：结果与之前一致。
- **Q31** 图集度量（先 `pgrep`，再 `design/demo/tools/check_atlas_budget.sh`）：仍为 2048×1024（本 feature 不新增贴图）；度量不了就写"未度量"。
