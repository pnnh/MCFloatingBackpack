# Quickstart: 064 验证

## 自动测试

`./gradlew test -PcleanRuntime -PnoJei`：`NestingRulesTest`（直接、一层、多层、深度上限、通用兜底、空容器、普通物品不扫描）、`NestedOriginsTest`（同背包同物品放行并清除、别的背包、别的物品、覆盖、清除）、`NestingWiringTest`（各入口源码里调用了判定、`FloatingBackpackItem` 重写了 `canFitInsideContainerItems`、`mainTargetOrderInternal` 只被垃圾桶还原用、语言键中英文齐全）。

## 游戏内（容器 `mcfb-c1`，生存模式；长命令写进数据包函数，见 `scripts/ai-gui/README.md`）

1. **直接禁**：手里一只皮革背包（光标）→ 点另一只背包面板的主区域、三个工具区、垃圾格：都被拒，光标上还是那只，操作栏有提示。
2. **各入口**：物品栏里的背包 Ctrl+点击进面板；地上的背包开着自动拾取走过去；箱子里的背包用"容器 → 面板"；ME 终端里放一只背包后"终端 → 面板"（若测不出就如实写）；创造模式界面里把背包点进面板。每条 `latest.log` 里没有 ERROR，物品数量守恒。
3. **深度扫描**：用数据包函数 `/give` 一个装着浮动背包的潜影盒（`minecraft:container` 组件）、一个装着空潜影盒的收纳袋；放进面板被拒（提示"里面含有浮动背包"）；空潜影盒、装圆石的潜影盒照常放入。
4. **容器拒收**：潜影盒界面里放浮动背包（点击、Shift 点击）；漏斗往潜影盒里推；收纳袋；旅行者背包的格子。精妙背包默认能放入，把配置 `containerItemsDisallowed` 改成 true（热改或重启）后拒收；记录实际看到的。
5. **旧数据**：用数据包函数造一只背包，其中主区域一格、垃圾桶一组、工具区一格各放一只浮动背包（旧格式）：升级后打开（日志一条 INFO）→ 都能拿起；拿起后点本背包的格子放得下（同包内重摆）；拿起后放进物品栏再放回**别的**背包被拒；整理（047）不丢；关闭、重开、快照都在。
6. **被拒时没有闪现**：被拒的一瞬间客户端画面不出现"放进去了"。
7. **测量（不属于必做）**：估一下一只空浮动背包编码后的字节数；有余力时把几十只满背包放进 ME 网络对比同样数量的潜影盒，记在 DELIVERY 里。
