# Quickstart: 可见可拖动空面板

## 准备

- Java 21，本仓库 Gradle Wrapper。
- 日常检查：`./gradlew runClient`。
- 本阶段不需要额外模组；不必开专用服务器。

## 自动检查

实现坐标钳制后：

```text
./gradlew test
```

覆盖：面板完全在屏内不变；左侧/上方越界被推回；右侧/下方越界后仍保留可点击标题区域。

## 客户端检查

1. 进入世界，确认默认不显示面板。按开关键（默认 `B`，以控制设置为准），面板出现；再按隐藏。
2. 打开控制设置，确认本模组分类下有开关键且可改绑。
3. 打开面板，拖动标题栏到屏幕一角，隐藏再打开，位置保持。
4. 完全退出客户端，再 `runClient` 进世界打开面板，位置与退出前一致（允许极小误差）。位置文件：`run/config/mcfloatingbackpack-panel.properties`。
5. 打开面板后按 E：物品栏与浮动面板同时可见。关闭物品栏后面板仍在。
6. 物品栏打开时再按开关键：面板隐藏，物品栏仍开着。
7. 打开一个箱子重复步骤 5 的「同时可见」检查。
8. 把面板往屏幕外拖再松开：面板仍留有可见可拖区域。

### 聊天界面

打开聊天（`T`）时，开关快捷键被忽略，避免把 `B` 打进聊天或误切面板。关掉聊天后再用快捷键。
