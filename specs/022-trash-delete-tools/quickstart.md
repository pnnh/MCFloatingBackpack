# Quickstart: 垃圾桶的删除手段与保护验收步骤

按宪法 V，下面的玩家可见行为都要在客户端会话里逐项验证；单元测试和编译不能代替。未验证的项在 tasks/DELIVERY 里保持"未验证"。

## 准备

```bash
pgrep -f "fml.modFolders=mcfloatingbackpack" || echo "没有游戏在跑"   # 有就不要启动第二个，也不要杀用户的游戏
./gradlew test
./gradlew runClient                                                       # 默认带 JEI；-PcompatRuntime 带兼容测试模组
```

进创造模式世界，拿：一只浮动背包、一个垃圾桶（放右侧区）、一个标签管理器（放下方区）；另外准备：圆石、腐肉、橡木原木、钻石镐（一把普通且磨损过的、一把带附魔、一把改了名）、一个装了东西的潜影盒、一只别的浮动背包、一个下界之星、一个箱子、一个木桶。

## A. 标题栏图标

- **Q1** 展开垃圾桶面板：标题栏左边是"垃圾桶"（英文 "Trash"），右边两个小图标（左倾倒、右删除），没有新贴图；窄面板下图标不遮挡文字。
- **Q2** 悬停倾倒图标 → 说明（带"垃圾"标签的物品移进垃圾桶；受保护和带数据的会跳过）；没有选区时悬停删除图标 → 置灰，说明"先在主区域用 Shift 选择物品"。

## B. 一键倾倒

- **Q3** 用标签管理器给圆石、腐肉的分类打"垃圾"标签；主区域放 3 格圆石、2 格腐肉、1 格钻石（没标）。点倾倒图标 → 5 个栈进垃圾桶（最后处理的在第 1 格），钻石还在，那 5 格变空。
- **Q4** 垃圾桶原有 4 组，再倾倒 3 组 → 共 7 组，不弹确认。垃圾桶已满 9 组，倾倒 3 组 → 直接执行，最旧的 3 组被销毁（服务端日志有调试行），不弹确认。
- **Q5** 主区域没有带"垃圾"标签的物品 → 点倾倒图标，什么都不发生，聊天区一句提示。
- **Q6** 左区/右区/下区里带"垃圾"标签的物品**不会**被倾倒。
- **Q7** 倾倒后把其中一组拿回来 → 与倾倒前一致。

## C. 保护

- **Q8** 选中一个潜影盒，在标签面板点加号 → 加号**仍可用**（可以加"食物"）；下拉里的"垃圾"预设是灰色，悬停列出潜影盒；点它、选中后回车、手打 `trash` 回车 → 都不添加，文本框保持，聊天区有提示。
- **Q9** 同样依次试：本模组的背包、标签管理器、垃圾桶、下界之星、龙蛋、鞘翅、不死图腾、信标、海洋之心、附魔金苹果 → 都被拦截；圆石正常能加"垃圾"。选区里圆石 + 潜影盒一起加"垃圾" → 整个被拒。
- **Q10** 受保护物品的分类已经带"垃圾"标签（先去掉保护再打，或用旧背包）→ 一键倾倒时被跳过。
- **Q11** 钻石镐的分类带"垃圾"：主区域放一把普通磨损的、一把附魔的、一把改名的、一个装了东西的潜影盒（先把它从保护里去掉）→ 一键倾倒只有磨损的那把进垃圾桶；药水、带图案的旗帜、玩家头颅、地图、书同理被跳过。
- **Q12** 数据包去掉 `never_trash` 里的某项后重新加载 → 该物品可以被标"垃圾"；往标签里加一个别的物品 → 被拦截。
- **Q13** 加载游戏时日志没有关于 `bundle` 标签条目缺失的报错。
- **Q14** 用删除图标、Delete 键、手动拖动删除受保护物品和附魔镐 → 都允许。

## D. 删除图标与 Shift 选区

- **Q15** 主区域 Shift 选 4 个有物品的格子 → 删除图标亮起；点它 → 4 个栈进垃圾桶，那 4 格变空，选区清空，图标重新置灰。
- **Q16** 选区里全是空格子 → 图标仍置灰。

## E. Delete 键（浮动面板主区域）

- **Q17** 有选区时按 Delete（macOS 是 Backspace）→ 同点删除图标。
- **Q18** 没有选区，鼠标悬停在有物品的主区域格子上按 Delete → 那一格整栈进垃圾桶。
- **Q19** 有选区，同时悬停在另一个没选中的格子上按 Delete → 删除的是选区。
- **Q20** 悬停在左区/右区/下区的格子或垃圾桶面板上按 Delete → 什么都不发生，**也不吞键**（比如按 Delete 时界面其它行为照旧）。
- **Q21** 标签面板展开时按 Delete → 失效；标签文本框有焦点时按 Backspace/Delete → 只作用于文本框。
- **Q22** 右侧区没有垃圾桶 → 按 Delete 什么都不发生。
- **Q23** 在 019 的宿主界面（没有其它界面）和打开着玩家物品栏/箱子这几种情况下，主区域的 Delete 都能用；Delete 不会让宿主让位，也不会触发世界动作。

## F. 二次确认

- **Q24** 垃圾桶为空，主区域放 20 个带"垃圾"标签的栈 → 点倾倒图标：浮动面板被半透明蒙版盖住，中央弹出"将永久销毁 11 组物品，确认吗？"和"确认""取消"。点"确认" → 垃圾桶里是最后 9 组，蒙版消失，服务端日志有销毁记录。
- **Q25** 同上再来一次，分别：点"取消"、点蒙版的空白处、点浮动面板之外（含垃圾桶面板）、按 ESC → 都只关闭弹窗，数据不变；**ESC 不关闭浮动面板、不弹暂停菜单**（在宿主界面和开着箱子两种情况下都测）。
- **Q26** 弹窗期间按 Delete、滚轮、拖动面板、拖缩放手柄、点关闭按钮 → Delete/滚轮/拖动/缩放无效；点关闭按钮只取消弹窗，不关面板。
- **Q27** 弹窗期间：把垃圾桶拿走（不可能点到，用热键）、按热键 B 关闭面板、按 E 打开别的界面 → 待确认被丢弃，回来后没有残留弹窗，什么都没执行。
- **Q28** 销毁恰好 9 组或更少 → 不弹确认；选 12 格点删除图标（垃圾桶空）→ 不弹；选 20 格 → 弹。
- **Q29** 把面板缩到最小（约 5×4 格）→ 弹窗文字与两个按钮完整显示在面板里。
- **Q30** 确认框出现后，在服务端（比如另一个窗口或指令）改变背包内容再点"确认"→ 服务端按真实内容重算，需要更多确认时拒绝并聊天提示"背包内容已变化，操作已取消"（没有条件构造就写"未验证"）。

## G. 原版玩家物品栏与箱子里的 Delete

- **Q31** 开着玩家物品栏（E），悬停在主物品栏（第 9～35 格）的物品上按 Delete → 整栈进垃圾桶。对 27 个格子各试一次。
- **Q32** 同界面悬停在快捷栏、装备栏、副手、合成格上按 Delete → 0 次触发、0 次吞键。
- **Q33** 开着箱子/大箱子/木桶/末影箱：悬停在箱子格子或下方玩家主物品栏（第 9～35 格）按 Delete → 整栈进垃圾桶；快捷栏不处理。
- **Q34** 打开潜影盒、漏斗、熔炉、创造模式物品栏 → 菜单格子上按 Delete 不触发、不吞键；主区域的 Delete 仍可用。
- **Q35** JEI 或配方书搜索框有焦点时按 Backspace 20 次 → 改的是搜索文字，**删除物品 0 次**。
- **Q36** 箱子里 Delete 之后，箱子内容变化同步给看着同一个箱子的另一位玩家（没有第二台机器就写"未验证"）。
- **Q37** 光标上拿着物品时在这些界面悬停某格按 Delete → 只处理悬停的格子，光标上的物品不动。
- **Q38** 浮动面板不可见或右侧区没有垃圾桶时，在这些界面按 Delete → 不拦截任何键，界面自己的行为照旧。

## H. 改键与兼容

- **Q39** 控制设置里有"删除到垃圾桶"（中英文名），默认键 macOS 是 Backspace；改成 X → X 触发、Backspace 不再触发也不被吞。
- **Q40** 把它改成 W（与前进冲突）→ 记录宿主界面上的表现（宿主先吞掉 W，Delete 功能不触发），写进已知限制，不要求修复。
- **Q41** 把一个模组界面配置成 OFF 并打开它 → 面板、垃圾桶面板、Delete 都不生效。
- **Q42** 021 的垃圾桶本体（点击丢入、拖放、拿回、Ctrl 恢复、限放 1 个）、018 的标签面板（加号、预设下拉、回车添加、点击添加）、011～020 的验证项 → 与之前一致。
