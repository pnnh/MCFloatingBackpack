# Quickstart: 垃圾桶（本体）验收步骤

按宪法 V，下面的玩家可见行为都要在客户端会话里逐项验证；单元测试和编译不能代替。未验证的项在 tasks/DELIVERY 里保持"未验证"。

## 准备

```bash
pgrep -f "fml.modFolders=mcfloatingbackpack" || echo "没有游戏在跑"   # 有就不要启动第二个，也不要杀用户的游戏
./gradlew test                                                            # 纯逻辑与资源测试
./gradlew runClient                                                       # 默认带 JEI；-PcompatRuntime 带兼容测试模组；-PnoJei 去掉 JEI
```

进创造模式世界，从创意栏拿一只浮动背包、一个垃圾桶、一个标签管理器，另外准备：各种物品若干（圆石 64、橡木原木、钻石镐带附魔、一个装了东西的潜影盒、一只别的浮动背包）、一个箱子。

## A. 物品与配方

- **Q1** 创意栏"浮动背包"页里有"垃圾桶 / Trash Can"，名字随语言切换（中文"垃圾桶"，英文 "Trash Can"）。
- **Q2** 在工作台按 `_ 铁锭 _ / 铁锭 炼药锅 铁锭 / _ 铁锭 _` 摆放（上、左、右、下各 1 个铁锭，中间 1 个炼药锅），得到 1 个垃圾桶；摆错（缺一个铁锭、换成别的）得不到。JEI 里能搜到并看到这个配方。
- **Q3** 垃圾桶在物品栏、手持、丢在地上、放进展示框，都是同一张平面贴图，最大堆叠 1。
- **Q4** 图集度量（按 018 的做法，先 `pgrep`）：仍为 2048×1024，退出码 0；度量不了就在 DELIVERY 写"未度量"。

## B. 展开 / 收起

- **Q5** 把垃圾桶放进**右侧区**的一个格子：左键点它 → 浮动面板**右边**出现垃圾桶面板（标题栏"垃圾桶" + 3×3 个凹槽），顶端与浮动面板顶端对齐，没有任何图标/按钮；物品没有被拿起。再次左键 → 收起。
- **Q6** 右侧区里的垃圾桶：右键 → 拿起；光标上有物品时左键 → 按普通规则交换 / 合并，**不**展开面板。
- **Q7** 把垃圾桶放进**主区域 / 左区 / 下区**：左键只是拿起，**展开面板 0 次**。
- **Q8** 展开后用右键把垃圾桶拿走、或放进别的区域 → 垃圾桶面板自动收起；放回右侧区再左键，能再次展开。
- **Q9** 展开后点浮动面板右上角的 ✕ 关闭浮动面板，再打开 → 垃圾桶面板是收起的。
- **Q10** 标签面板（下区放标签管理器）与垃圾桶面板**同时展开**，互不影响；标签面板里的操作不受垃圾桶影响。
- **Q11** 点击垃圾桶面板的标题栏、格子之间的空隙、格子：下面的界面（宿主界面 / 箱子 / 玩家物品栏）的格子**一次都没被点到**；在它上面滚动滚轮，下面的界面也不动。

## C. 丢入与拿回（点击）

- **Q12** 宿主界面（没开别的界面）：用面板光标拿起 20 个圆石，左键点垃圾桶面板的任意位置（含空格子、标题栏）→ 20 个圆石作为**一组**出现在第 1 格，光标变空。
- **Q13** 再丢一组圆石 → 第 1 格是新的，上一组后移到第 2 格，**不合并**；再丢别的物品，顺序始终最新在前。
- **Q14** 开着玩家物品栏（E）或箱子：在容器里拿起一组物品（菜单光标），左键点垃圾桶 → 这组被丢进去，容器里没有残留，鼠标上的物品消失。
- **Q15** 光标为空，点有物品的垃圾格 → 那一组被拿起到光标，后面的前移；点空格子什么都不发生；光标非空时点有物品的格子 → 是**追加**（不是交换）；右键在垃圾桶面板上什么都不做。

## D. 拖放（松开在垃圾桶上）——重点

- **Q16** 宿主界面：用面板光标拿着一组物品，在**主区域**按下左键不放，拖到垃圾桶上松开 → 整组丢进垃圾桶；主区域没有发生任何分配或放置，013 的预览消失。
- **Q17** 同上，但按下在**下 / 左 / 右工具区**的格子上（先拿起再拖）→ 同样丢进垃圾桶。
- **Q18** 开着**箱子**：在箱子的一个物品上按下（原版拿起）→ 按住拖到垃圾桶上松开 → 丢进垃圾桶；之后箱子的点击、拖动依然正常（原版没有卡在"拖动分配"状态）；物品没有被扔出窗口，也没有落进被垃圾桶遮住的格子。
- **Q19** 开着**玩家物品栏**：先点起一组物品（光标上带着）→ 在物品栏另一个格子上按下不放 → 拖到垃圾桶上松开 → 丢进垃圾桶，之后物品栏依然正常。
- **Q20** 快速点击拿起一个物品，**在原处**松开 → 只是拿起，**不会**丢进垃圾桶。
- **Q21** 在垃圾桶上按下、再松开 → 只丢一次，不重复追加。

## E. 满 9 组与销毁

- **Q22** 连续丢 12 次不同物品（可用创造模式拿各种物品）→ 垃圾桶始终 9 组，最新在第 1 格；最旧的 3 次被挤出。服务端日志（调试级别）有 3 行"Trash can destroyed …"，含物品与数量。
- **Q23** 满 9 组时拿起一组 → 剩 8 组，再丢一组 → 不销毁任何东西（日志没有新增）。

## F. Ctrl 恢复

- **Q24** 垃圾桶有 3 组、主区域有同种堆叠未满：Ctrl+点第 1 格 → 先叠进已有堆叠，余下放进空格；这一组从垃圾桶消失。
- **Q25** 主区域只剩 1 个空格，垃圾桶有 3 组不同物品：Ctrl 拖过这 3 格 → 能放下的先放（按格子顺序），放不下的留在垃圾桶原位，不报错。
- **Q26** 主区域已满：Ctrl+点一组 → 什么都不发生，垃圾桶不变。
- **Q27** 开着箱子时对垃圾桶做 Ctrl 恢复 → 物品回到浮动背包主区域，箱子不变。
- **Q28** 主区域里按住 Ctrl 点一个物品 → 仍是 011/012 的行为（转到玩家物品栏 / 容器），**不会**进垃圾桶；按住 Ctrl 且光标非空点垃圾桶 → 是追加。
- **Q29** 011/012 的 Ctrl 转移验证项（玩家物品栏 ↔ 浮动背包、开箱子时的转入转出）结果与之前一致。

## G. 限放 1 个

- **Q30** 右侧区已有 1 个垃圾桶，光标上再拿一个，点右侧区另一个空格 → 放不进去，光标上的还在，聊天区出现"这里只能放一个"之类的提示（含中英文）。
- **Q31** 点右侧区里**那个垃圾桶所在的格子** → 允许交换。点右侧区里装着别的物品的格子（光标是垃圾桶）→ 拒绝并提示。
- **Q32** 下方区已有 1 个标签管理器，再放第 2 个 → 拒绝并提示；用它自己的格子交换允许。
- **Q33** 主区域 / 左区放多个垃圾桶或标签管理器 → 允许；垃圾桶放进下区、标签管理器放进右侧区 → 允许（限制只针对"垃圾桶在右侧区""标签管理器在下方区"）。
- **Q34** 打开 018 测试时留下的、下方区有 2 个标签管理器的旧背包（如果还有）→ 它们都还在，标签面板仍能用，放不进第 3 个。
- **Q35** Alt（macOS 的 Option）与主手交换：如果会让该区域多出第 2 个垃圾桶 / 标签管理器 → 同样被拒绝。

## H. 持久与隔离

- **Q36** 丢进几组物品后：关闭浮动面板再打开、退出世界再进入 → 内容仍在。
- **Q37** 把垃圾桶从右侧区拿走（面板收起）→ 再放回右侧区展开 → 内容还在。
- **Q38** 两只背包：在一只上丢物品，另一只上看不到。
- **Q39** 垃圾桶里有内容的背包用锻造台升级 → 内容保留。
- **Q40** 021 之前保存的旧背包 → 垃圾桶为空，不报错。
- **Q41** 把别的浮动背包、垃圾桶、标签管理器、装满东西的潜影盒丢进去，再拿回来 → 数据完整（背包里的东西、潜影盒里的东西都在）。
- **Q42** 极端大的物品栈（尽量填满的嵌套背包）→ 若被体积保护拒绝，聊天区有提示且物品还在光标上；记录这个上限，DELIVERY 里如实写。

## I. 兼容与界面

- **Q43** 垃圾桶面板展开时，JEI（FULL 档位）的配料列表避开它，不被遮挡；把配置里 jei 改成 GENERIC / OFF 后，JEI 不再避让（沿用 020 的行为）。
- **Q44** 把一个模组界面配置成 OFF 并打开它 → 垃圾桶面板整体不画、不能点；回到别的界面后又出现，展开状态还在。
- **Q45** 把游戏窗口缩窄、或把浮动面板拖到靠近右边缘 → 垃圾桶面板超出窗口的部分被裁剪，窗口拉宽后又完整显示，其它功能不受影响。
- **Q46** 右侧区滚动 / 缩小面板后，垃圾桶不在可见格子里 → 垃圾桶面板**不收起**（按区域整体内容判断）。
