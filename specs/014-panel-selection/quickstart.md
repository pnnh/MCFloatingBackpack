# Quickstart: 选区的客户端验收

宪法 V 条：玩家可见的行为必须在真实客户端会话里验证。以下在**创造模式**世界、`./gradlew runClient` 里做；第 6 节需要 `./gradlew runClientCompat`。HUD（没开界面）与打开着界面（按 E、箱子）各做一遍。**开始前确认没有正在运行的 Minecraft 客户端**（不要用会 `pkill` 客户端的脚本）。

## 准备

1. 取一只铁背包放在主手，右键打开面板。
2. 在面板里放：3 格圆石（各不同数量）、2 格木板、1 格铁锭，中间留几个空格，让它们分布在**不同的行**。
3. 再准备一个空箱子（第 4 节）。

## 一、选择（US1）

1. 按住 Shift 单击一个有物品的格子 → 该格出现金色内边框，物品没有被拿起。
2. 再按住 Shift 单击同一格 → 边框消失（切换）。
3. 按住 Shift 从一行最左拖到最右（含空格子）→ 这一行每格都出现金色边框，起点也在。
4. 按住 Shift，**从一个已选中的格子**开始拖过几个未选格子 → 起点仍然选中，其他格子加入；没有任何格子被取消。
5. 不按 Shift，单击面板里任意一个格子 → 整个选区消失，该点击照常（拿起/放下）。
6. 光标拿着物品时按住 Shift 单击一个格子 → 只出现边框，光标上的物品没变，格子里的物品没变。
7. 把鼠标悬停在已选格子上 → 金色边框和悬停高亮都看得见；做 013 的拖动均分预览 → 金色边框与预览高亮能区分。

## 二、批量转出（US2）

8. 选中 5 个有物品的格子（含 1 个空格子），没有打开任何容器，按住 Ctrl（macOS Command）点击其中**一个**选中格并松开 → 5 格里有物品的都进了玩家物品栏；选区仍然在（已转空的格子仍有边框）。
9. 同样的选区，打开箱子（面板保持），Ctrl+点击选中格并松开 → 物品进了箱子。
10. 把箱子（或物品栏）塞到只剩 3 格空位再试 → 恰好下标最小的几个有物品的格子被转走，其余留在原格；选区不变。
11. 目标完全放不下 → 没有物品移动，选区不变。
12. 按住 Ctrl 点击一个**未选中**的格子 → 与 011/012 的现有行为一致（只转这一格，或 Ctrl+拖动），选区不变，被点击的格子没有变成选中。
13. Ctrl 在已选格子上按下，**松开鼠标前先松开 Ctrl**，再松开鼠标 → 没有物品移动。
14. Ctrl 在已选格子上按下后移动鼠标经过别的格子再松开 → 只发生一次批量转出，没有额外格子被转。
15. 光标拿着物品时按住 Ctrl 点击已选格子 → 不触发批量转出，选区不变。

## 三、生命周期（US3）

16. 选中几格后滚动面板（让部分选中格滚出视野再滚回来）→ 回来后仍是选中；滚出视野时 Ctrl 批量转出，滚出的选中格也被转走。
17. 拖动缩放面板的行列数 → 选区仍对着同样的物品。
18. 关闭面板再打开 → 没有选区。
19. HUD 下建立选区，按 E 打开物品栏 → 选区保持；再关掉物品栏 → 保持。
20. 换一只不同等级的背包打开 → 没有选区。
21. 选中一个空格子，之后手动往里放一个物品 → 仍然选中。

## 四、主手交换改键与回归（US4）

22. 没有打开任何界面。主手是背包本身时服务端不会交换，所以要把背包放在**副手**并用副手打开面板，主手拿别的物品（如圆石）。按住 **Alt（macOS Option）** 点击面板里一个有物品的格子 → 主手物品与该格交换。如果无法这样打开面板，这一项记"未验证"。
23. 同样情况按住 **Shift** 点击 → 只改选区，没有交换。
24. 光标拿着物品、没有打开界面时 Alt+点击 → **立即**交换（不是松开才发生）。
25. 打开着界面时 Alt+点击面板格子 → 与普通点击一致。
26. 同时按 Shift+Alt 点击 → 按选区处理，没有交换。
27. Ctrl+Shift 点击、Shift+右键点击 → 什么都不发生（不拿起、不放下、不转移），选区不变。
28. 重跑 013 quickstart 一～四（拖动均分、右键拖动、拖动收集、双击收集）→ 结果与 013 完成时一致，唯一差别是这些点击会清空选区。
29. 重跑 011/012 的 Ctrl 单格、Ctrl 拖动转出（未选格子）→ 结果相同。

## 五、守恒与日志

30. 做 50 次以上的选择与批量转出（含目标已满、选区含空格子、转出过程中滚动）→ 背包与目标里同一种物品的总数前后相等。
31. `run/logs/latest.log` 没有新增报错。

## 六、第三方界面（`./gradlew runClientCompat`）

32. 打开精妙背包或旅行者背包，面板保持，重做 8、9：物品进入它们的存储，选区不变。
33. 在它们自己的格子里按 Shift/Ctrl 点击 → 它们自己的行为不变（面板选区不介入）。

## 记录要求
