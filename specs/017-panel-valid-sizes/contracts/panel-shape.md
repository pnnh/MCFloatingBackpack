# Contract: 面板合法尺寸与缩小后的箭头

## 1. 合法尺寸

对当前背包的格子数 `main / left / right / bottom`，尺寸 `(cols, rows)`（主区域可见列数 × 可见行数）合法当且仅当：

```text
3 ≤ cols ≤ 9
main % cols == 0                       主区域滚到哪里都没有半行
cols + 2 ≤ bottom                      下区放得下可见格数
3 ≤ rows ≤ min(left, right, main/cols)  左右区、主区域都不会出现空位
```

合法时，四块区域在**任何滚动位置**都没有实心格子（由穷举测试保证）。

## 2. 拖动缩放手柄

- 目标尺寸 = 抓取时的尺寸 + 鼠标位移（每格 18 像素，四舍五入），夹到 `cols ∈ [3,9]`、`rows ≥ 3`。
- **列数**：目标列数合法 → 采用；不合法 → 保持当前列数。
- **行数**：用**采用后的列数**判定，目标行数合法 → 采用；不合法 → 保持当前行数。
- 两个方向各自判断；一个方向被挡住不影响另一个方向。
- 不合法的目标**不产生任何变化**（不吸附、不抖动、不提示），玩家继续拖到合法目标才变化。
- 面板最小仍是主区域 3×3（面板 5×4）；缩放手柄的位置与命中不变。

## 3. 其他入口（`layout()` 每 tick 执行）

| 入口 | 处理 |
|---|---|
| 已保存的偏好（`FloatingPanelConfig` 读出的任意值） | 列：不超过偏好（且不超过屏幕允许值）的最大合法列数，没有则最小合法列数；行：夹到 `[3, min(屏幕允许, maxRows)]` |
| 没有偏好（自动适应） | 取"屏幕放得下的最大合法尺寸"（默认形状：9 列 × 等级默认行数） |
| 换背包 / 升级 / 同步长度变化 | 下一次 `layout()` 落到合法尺寸 |
| 屏幕变小 | 同上；`MIN_VISIBLE_CELLS = 3` 仍压过屏幕过小的情况 |
| 没有合法形状 / 格子数尚未上报 | 不限制，行为与 016 完全一致；填充格不绘制的兜底保留 |

配置文件格式不变；非法值读入后由 `layout()` 修正，之后保存的是合法值。

## 4. 滚动箭头（缩小）

| 项 | 016 | 017 |
|---|---|---|
| 外框最大尺寸 | 9 宽 × 5 深 | **7 宽 × 4 深** |
| 深色三角形 | 行宽 1、3、5、7（深 4） | 行宽 1、3、5（深 3） |
| 尖端位置 | 距区域边缘 1 像素 | **紧贴区域最外一个像素**（间隙 0） |
| 出现条件 | 哪侧有隐藏内容就显示，两侧都有则两侧都显示，放得下则不显示 | **不变** |
| 命中 | 不参与 | **不变** |
| 颜色 | 深灰 `0xFF3A3A3A` + 浅色 `0xFFF2F2F2` 外框 | **不变** |

箭头位置：主区域与左右区在上/下边缘的中点（朝上/下）；下区在左/右边缘的中点（朝左/右）。

## 5. 不变的部分

016 的布局（四区、下区横跨整个面板、无空角）、滚动（滚轮、各区独立）、容量规则（左右 = 默认行数，下 = 默认列数 + 2）、最小 5×4、工具区只做单击、011～014 只作用于主区域，以及网络协议（仍为 `"7"`）和存储，**全部不变**。
