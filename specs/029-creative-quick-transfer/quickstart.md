# Quickstart: 创造界面里的 Ctrl 快速转移验收步骤

按宪法 V，玩家可见行为都要在客户端会话里验证；未验证的项在 tasks/DELIVERY 里保持"未验证"。

## 准备

```bash
pgrep -f "fml.modFolders=mcfloatingbackpack" || echo "没有游戏在跑"   # 有就不要启动第二个，也不要杀用户的游戏
./gradlew test
./gradlew runClient
```

创造模式世界；面板打开；物品栏里放一些不同的物品（主物品栏与快捷栏都有）。每一项都**先做创造界面，再在生存物品栏界面做同一操作对照**。

## A. 物品栏 → 面板（US1）

- **A1** 创造界面**物品栏标签页**：按住 Ctrl 点**主物品栏**的一格：整组转进面板，物品栏该格变空。
- **A2** 同上点**快捷栏第 0 格**与**第 8 格**：转进面板的恰是你点的那一格（验证下标换算，F1）。
- **A3** 切到**物品标签页**，Ctrl+点击快捷栏格子：同样转进面板。
- **A4** 面板放不下：放不下的留在原格。
- **A5** Ctrl+点击放着背包本身的格子：背包不会被转进它自己的面板。
- **A6** Ctrl+点击护甲格、合成格、副手格：不拦截（原版行为）。

## B. 面板 → 物品栏（US2）

- **B1** 物品栏标签页：Ctrl+点击面板里有物品的格子：物品进入物品栏（先叠加后空格），在对应格子马上看到。
- **B2** **物品标签页**下做同样的事（物品进了不在屏幕上的物品栏格子），然后**切到物品栏标签页**：看到的是真实内容。
- **B3** 物品栏满了：放不下的留在面板。

## C. 拖动与选区（US3）

- **C1** 按住 Ctrl 拖过多个物品栏格子：依次转进面板。
- **C2** 面板里 Shift 选几格，按住 Ctrl 点其中一格：整个选区转进物品栏。

## D. 守恒与回归（US4）

- **D1** B2 之后，在物品栏标签页里拿起、放下**其它**格子 20 次：刚转进来的物品还在，没有被旧内容覆盖。
- **D2** 创造物品列表里的物品按 Ctrl+点击：是原版行为（不被拦截，也不转进面板）。
- **D3** 生存模式物品栏界面、箱子界面：011/012/014 的验证项与之前一致。
- **D4** 图集度量（先 `pgrep`，再 `design/demo/tools/check_atlas_budget.sh`）：仍为 2048×1024。
