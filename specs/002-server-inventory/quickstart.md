# Quickstart: 服务端库存与面板内取放

## 准备

- Java 21，本仓库 Gradle。
- `./gradlew runClient`（集成服务端）即可验单人。
- 联机验收：`runServer` + 客户端，**两端都要装本模组**。

## 自动检查

实现点击逻辑后：

```text
./gradlew test
```

覆盖：空光标拾取、空槽放下、同类堆叠合并、异类交换、满堆叠拒绝溢出丢物。

## 客户端检查

1. 新世界打开浮动面板：27 空槽，无物品。
2. **无按 E**：主手拿一组物品，对空槽 **Shift+左键**，物品进入槽，主手空。
3. 对已有物品的槽 **Shift+左键**：物品回到主手（或与主手交换）。
4. 左键拾取到面板光标，再点另一空槽放下；点异类槽交换。
5. 隐藏面板再打开：内容仍在。
6. 退出世界重进：内容仍在。
7. 按 E 打开物品栏时：面板仍可见；本阶段不要求与物品栏光标互拖；Shift 主手路径可禁用。
8. （可选）`runServer` 重进同一玩家：内容仍在。

## 明确不做（本 feature）

- 物品栏/箱子 GUI 与浮动背包之间拖拽（M3）。
- 精妙 / 旅行者背包兼容（M4）。
