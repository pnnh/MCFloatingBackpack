# Quickstart: 005 背包道具化验收

## 构建

```bash
./gradlew compileJava test
./gradlew runClient
```

开发客户端默认通过 `localRuntime` 加载 JEI。若需关闭：`./gradlew runClient -PnoJei`。

## 手工检查清单

### 门禁

1. 新档，清空物品栏，按 **B** → 面板不出现，有提示。
2. 创造模式取出「皮革浮动背包」到主手，**无需打开物品栏**，按 **B** → 面板在游戏 HUD 上打开；再按 **B** 或 **ESC** 关闭（ESC 不进入暂停菜单）。
3. 主手持背包，未瞄准方块时右键 → 面板切换。
4. 暂停 / 设置等游戏菜单上不显示面板；打开原版物品栏（E）时面板可与容器共存。

### 多背包顺序

1. 主手与背包格 12 各放一只；按 B → 操作主手那只（向主手背包存标志物验证）。
2. 清空主手，仅槽 12 有背包 → 按 B 打开槽 12。

### 内容随物品

1. 向面板放入若干物品，关闭。
2. 丢弃背包再捡起，再打开 → 内容一致。
3. 放入箱子再取出 → 内容一致。

### 胸甲与背负

1. 将背包装入胸甲栏（或装备）。
2. F5 第三人称 → 背部可见占位模型。
3. 仅胸甲有背包时按 B → 可打开。
4. 卸下且身上无其它背包 → 按 B 无效。

### JEI / 依赖

1. `runClient` 中 JEI 可搜索到浮动背包。
2. 确认 `mods.toml` 未将 JEI 标为 required；无 JEI 的实例可启动本模组。

### 回归

1. 持有背包时，打开原版物品栏，浮动面板与原版槽互拖仍可用（003）。
2. 确认玩家不再拥有「无物品的全局 Attachment 背包」。

## 预期失败（应发生）

- 无背包时 Shift 存取无效。
- 打开面板后把当前唯一背包扔出，再点击槽位 → 被拒绝或面板关闭。
