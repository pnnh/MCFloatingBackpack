# Quickstart: 012 转出到打开着的容器 验收

> **019 说明**：019 起"没有打开任何界面（HUD）"的场景，指的是面板在**透明宿主界面**上（按 B 打开后不能移动和转向）；验证步骤与预期结果不变。详见 `specs/019-fallback-host-screen/`。

## 构建与自动化检查

```bash
./gradlew compileJava test
```

覆盖：`OpenContainerDelivery` 的临时槽位选择、换出换回、循环上限、异常、守恒（用假菜单）。**不能证明在真实菜单里可用**——宪法 V 条要求下面的客户端会话验证。

## 客户端会话验证（必须实际执行）

```bash
./gradlew runClient          # 原版部分
./gradlew runClientCompat    # 精妙背包与旅行者背包部分
```

创造模式，取出皮革背包，面板里放几种物品（普通方块、可堆叠物品、不可堆叠物品、一件升级/工具类物品）。macOS 上"Ctrl"指 **Command 键**。

### 一、原版容器（US1，`runClient`）

1. 打开箱子，面板可见：Command+点击面板里一个堆叠 → 进入箱子，面板该格清空，玩家物品栏不变。（FR-001）
2. 箱子里已有同种半堆叠：先并入，多出的占空格；总数不变。
3. 箱子塞满：能并入的部分进入，其余**留在面板**，不进玩家物品栏。（FR-007）
4. 把玩家物品栏塞满再试：仍能存入箱子。（FR-008）
5. 木桶、末影箱、潜影盒、漏斗、发射器各试一次。
6. 与 Shift+点击对比：在同一个箱子里 Shift+点击玩家物品栏里同一种物品，落点应一致。（SC-002）

### 二、非存储类界面（FR-005）

7. 熔炉：Command+点击面板里的矿石 → 进原料格；点击木头/煤 → 进燃料格（与 Shift+点击一致）。
8. 工作台：点击面板里的物品 → 先进合成格；合成格放不下时物品留在**玩家物品栏**（不是容器里），总数不变。
9. 铁砧、酿造台、村民交易各试一次，结果与在里面 Shift+点击一致。

### 三、第三方容器（US2，`runClientCompat`）

10. 精妙背包：Command+点击面板里的普通物品 → 进它的存储区；点击升级物品 → 与 Shift+点击物品栏里同一升级物品一致。（SC-002）
11. 旅行者背包：普通物品、工具类物品各一次，与 Shift+点击物品栏里同物品一致。
12. **物品栏已满 + 手持模组背包**：精妙背包和旅行者背包各做一次，确认物品不丢、手持的背包物品完好无损、转移正常。（research 的主要风险）
13. 容器放不下或拒收时，物品留在面板里，不报错。

### 四、拖动（US3）

14. 打开箱子，面板一行 9 个堆叠，按住 Command 和左键滑过 → 9 个依次进入箱子，3 秒内完成。（SC-006）
15. 拖动途中关闭容器（按 E/ESC）→ 之后的槽位转到玩家物品栏；已存入的不受影响，总数不变。
16. 拖动途中容器放满 → 放不下的槽位保持不变。

### 五、不能被影响的（US4）

17. 没有任何界面（HUD）、只开着物品栏（E）：面板转出 → 玩家物品栏（011 行为）。（SC-004）
18. 箱子打开时 Command+点击玩家物品栏槽位 → 进入浮动背包（011 方向不变）。
19. Shift+点击玩家物品栏槽位 → 进入箱子（原版）；面板隐藏时 Command 手势与原版一致。（SC-005）
20. 011 的 quickstart 重跑一遍，结果相同。

### 六、守恒与异常（SC-003）

- 做 30 次以上转移（含容器满、拒收、物品栏满、两个模组），每次前后清点该种物品总数，应完全相等。
- `run/logs/latest.log` 里搜 `mcfloatingbackpack`，不应出现"守恒检查失败"或"转出异常"的日志；若出现，记下菜单类名。

### 七、平台

- 本机验证 macOS（Command）。Windows/Linux 无法验证，登记为未验证。

# 补充（2026-11-05）：反向——容器 → 浮动背包

## 八、反向转移（US5）

**原版容器（`runClient`）**

21. 打开箱子（里面放几种物品），面板可见：Command+点击箱子里一个堆叠 → 进入浮动背包，箱子该格清空，玩家物品栏不变。（FR-017、SC-008）
22. 浮动背包里已有同种半堆叠：先并入，多出的占空格；总数不变。
23. 浮动背包塞满再试：放不下的部分**留在箱子原槽位**，不丢失。（FR-020）
24. 打开熔炉：Command+点击**输出槽** → 本功能不处理（保持原样）；点击原料/燃料槽 → 进入浮动背包。打开工作台：点击合成输出 → 不处理。铁砧、村民交易输出同理。（FR-019）
25. 按住 Command 和左键滑过箱子一行 9 格 → 9 个依次进入浮动背包，3 秒内完成；松开 Command 或鼠标立即停止。（FR-018、SC-009）
26. 起点在玩家物品栏槽位，滑过箱子槽位 → 两类槽位都进入浮动背包；起点在面板槽位 → 转出（正向），不会把容器里的东西拿进来。（FR-018）
27. 同时按着 Command 和 Shift 点击容器槽位 → 本功能不处理，保持原样。（FR-021）
28. 面板隐藏时 Command+点击容器槽位 → 与没有本功能时一致。

**第三方容器（`runClientCompat`）**

29. 精妙背包：Command+点击它的存储槽位 → 进入浮动背包；点击一个堆叠超过 64 的槽位 → 只转走背包放得下的数量，其余留在原槽位。（SC-008）
30. 精妙背包：被滚动隐藏的槽位、升级槽、锁定/过滤槽位上点击，结果合理（隐藏槽位不应被命中）；并确认**它自己的 Ctrl 用法**没有被破坏（不确定，见 spec 假设）。
31. 旅行者背包：存储槽位、工具槽、记忆槽各点一次，结果合理（工具槽里的工具能被取出）。
32. 两个模组界面里，其中的**玩家物品栏槽位** Command+点击 → 进入浮动背包（011 的方向，现在对第三方界面也生效）。

**守恒与日志（SC-010）**

- 30 次以上反向转移（含背包满、大堆叠、输出槽）前后清点总数应完全相等；`run/logs/latest.log` 里不应出现守恒检查失败、回退路径或异常的日志。
