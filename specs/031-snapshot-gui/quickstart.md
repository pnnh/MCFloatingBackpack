# Quickstart: 快照管理界面验证

先 `pgrep -f "fml.modFolders=mcfloatingbackpack"`：有客户端在运行就不要再启动，也不要杀它；改了代码要重启客户端才生效。需要 op 与非 op 两种身份：单人游戏开作弊（房主是 op）、关作弊（普通玩家）各做一遍；有第二个账号更好。

## A. 入口（Story 1）

1. 任意世界：`/mcfb snapshot gui` → 界面打开；ESC 关闭。控制台执行（专用服务器）→ 提示需要玩家。
2. 控制设置里找到"背包快照"：默认**未绑定**；绑定一个键后，在世界里按它打开；在聊天框里按它不触发；**浮动面板打开着时（宿主在场）按它也能打开**（research D7 要验证的点）。
3. 打开浮动面板：标题栏有一个小按钮（关闭按钮左边），悬停提示"背包快照"；点击打开界面；**关闭界面后浮动面板的位置、大小、滚动、选区原样**。把面板拖窄到极限：按钮隐藏，编号不与按钮重叠。
4. 手里**没有任何背包**时用命令或快捷键打开：照样能用。

## B. 玩家（非 op）的视图（Story 1、2、6）

1. 列表只含自己最后使用过的背包，最近的在前；每行有编号、档位、版本数、所有者、距今；超过一页能翻页。
2. 选中一只：右边列出各个版本；选中一份：显示预览（主区域格子），悬停有原版物品提示，点击无反应；带附魔/名称的物品照常。
3. **没有**"全部"切换、过滤框、恢复、删除、清理（不是灰色，是不存在）。
4. 别的玩家的背包不出现（有第二个账号时验证）。

## C. 管理员（op）的视图与动作（Story 3、4、5）

1. 有"我的/全部"切换；"全部"列出所有玩家的；所有者框输入玩家名只列该玩家的；不活跃天数输入 30 只列早于 30 天的。
2. 选中一份快照点"恢复"：自己多一只新背包（内容与预览一致，**原背包不变**）；改目标为另一在线玩家后再恢复，那名玩家得到；物品栏满时掉落；状态行显示结果。
3. "删除这一份"：只删这一份，列表刷新；"删除全部"先出现确认，取消零变化，确认后删除；删到最后一份该背包从列表消失。
4. 清理：输入天数点预览，状态行显示数量且**什么都没删**；确认才删；`0` 是全部。
5. 关闭作弊后（或 `/deop`）重开界面：op 控件消失；界面打开期间被取消 op，下一次操作后控件消失，动作被拒绝。

## D. 布局（FR-011）

GUI 缩放 1、2、3、4、自动各试一次，窗口缩到很小：所有控件与预览不溢出；108 格的预览（网络下界合金背包）可滚动。

## E. 回归

030 的命令（`list`、`info`、`restore`、`delete`、`trim`）输出文字与行为不变；浮动面板其它功能与 011～029 不受影响；图集度量 2048×1024。
