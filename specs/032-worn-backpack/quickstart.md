# Quickstart: 统一的"背着的背包"查找验证

这是一次重构，玩家可见行为必须与 031 之后完全一致。先 `pgrep -f "fml.modFolders=mcfloatingbackpack"`：有客户端在运行就不要再启动；改了代码要重启客户端。**开发世界用 2026-11-09 之后新建的那个**（`runClient` 现在带着所有开发期模组）。

## A. 行为不变（US1，对照 spec 的 8 个场景）

准备：创造世界，五档背包若干只。

1. 背包**只在胸甲槽**（Shift+右键换上）：按 B 打开它；背上有模型（Shift+右键、F5 看）。
2. 背包在**主手**，胸甲槽也有一只：按 B 打开主手那只；背上仍是胸甲那只。
3. 背包只在**副手**：按 B 打开它；背上没有模型。
4. 背包在**物品栏里**（不在手上、不在胸甲槽）：按 B 打开下标最小的那只；背上没有模型。
5. 物品栏里两只、胸甲一只：按 B 打开胸甲那只。
6. 打开面板后把胸甲槽的背包摘下：面板关闭或改指向新找到的那只（与改动前一致）。
7. 给背包装上自动拾取、放进地面物品：针对按 B 会打开的那只。
8. 两个客户端（或单人游戏里看别的玩家，没有条件就写"未验证"）：别人背着的模型照常显示。

## B. 面板各功能没有回归（US1）

在胸甲槽背着背包时：打开面板、点击放入拿出、Ctrl 快速转移（物品栏 → 面板、面板 → 物品栏，**背包自己不会被转进它自己**）、标签管理器、垃圾桶、自动拾取、升级、编号显示、030 的快照命令与 031 的界面（打开与关闭后面板状态不变）。
