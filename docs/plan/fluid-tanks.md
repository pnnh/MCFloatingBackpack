# 液体罐与管子（048 / 049 / 050）

状态：方案已与用户确认（2026-11-12）。**048 已实现**（代码与单元测试完成，游戏里的验证见 `specs/048-fluid-tanks/DELIVERY.md`，用户确认待做）；049、050 尚未建 spec。按 Spec Kit 一次只做一个 feature：048 → 049 → 050。

048 与本方案的差别（plan 阶段查证后）：档次限制对**三个工具区**都生效（不只底部区），主区域不限；被拒时有动作栏/聊天提示；液量放在背包数据里（可选字段 `fluids`），数据修订 1→2、协议号 18→19。

## 1. 玩法

- 罐子放在面板**底部工具区**生效；左、右区可放但不生效，也不计入互斥。
- **同一种液体只能放一个罐，不论档次**：皮水罐与铁、金、下界合金水罐互斥。同格换成同液体的另一档允许，放到别的格被拒绝。
- 手持某种管子时，找 **B 键会打开的那个背包**（`WornBackpacks.resolvePlayer`：手 → 背 → 物品栏），只看它的罐子；别的背包不参与。
- 效果只取决于**罐子自己的档次**，与放在哪档背包里无关。
- 满了或空了在聊天栏提示一次；防刷屏用短冷却。

## 2. 液体与档次

| 液体 | 皮 | 铁 | 金 | 下界合金 | 一次的量 |
|---|---|---|---|---|---|
| 水 | ✓ | ✓ | ✓ | ✓ | 1000 mB |
| 原油（`#c:crude_oil` 流体标签） | ✓ | ✓ | ✓ | ✓ | 1000 mB |
| 岩浆 | ✗ | ✓ | ✓ | ✓ | 1000 mB |
| 牛奶 | ✓ | ✓ | ✓ | ✓ | 1000 mB |
| 蜂蜜 | ✓ | ✓ | ✓ | ✓ | 250 mB（一瓶） |

共 4 + 5×3 = 19 种罐 + 5 种管子（管子不分档）= 24 个物品。

**放入规则**：罐子档次 ≤ 背包档次。皮罐放任何背包；铁罐放铁及以上；金罐放金及以上；下界合金罐只放下界合金背包。钻石背包不放下界合金罐。服务端校验，做法与 038 通用扩展按背包档次生效相近。

**容量**（1 桶 = 1000 mB）：皮 8、铁 16、金 64、下界合金 256。

## 3. 配方（提案）

- 皮罐：皮革围一圈，上中放玻璃，中间放对应容器。
- 铁罐：铁锭围一圈，中间放对应容器；岩浆罐直接用岩浆桶。
- 金罐：同液体铁罐 + 8 金锭。
- 下界合金罐：同液体金罐 + 下界合金锭 + 锻造模板，走锻造台。
- 中间的容器：水=水桶，岩浆=岩浆桶，牛奶=牛奶桶，蜂蜜=蜂蜜瓶；合成后退回空桶或空瓶。
- 原油没有原版原料：用"空桶 + 煤炭块"代替。
- 管子：铁锭围一圈，中间放对应容器（原油管同上）。

## 4. 管子的操作

| 操作 | 水、原油、岩浆管 | 牛奶管 | 蜂蜜管 |
|---|---|---|---|
| 右键 | 对准源方块 = 吸收 | 对准牛（含山羊）= 吸收 | 对准蜂巢 = 吸收 |
| 左键 | 把液体作为源方块放下 | — | — |
| **潜行 + 右键** | 排放到容器 | 排放到容器 | 排放到容器 |

- 蜂巢沿用原版：蜂蜜满级才能取，没有烟熏会激怒蜜蜂。牛奶只能挤成年牛。
- 排放到容器：消耗一个空桶（蜂蜜用玻璃瓶），得到装满的容器。
  - 空容器来源：**背包主区域 + 玩家物品栏（含快捷栏）**。
  - 装满的容器进玩家物品栏，满了掉在地上（可能被自动拾取，正常）。
  - 没有空容器：聊天栏提示。
  - 原油：模组一般允许用原版铁桶装油；没有对应的桶物品就提示"这种液体没有桶"。
- 左键放置需要拦截 `LeftClickBlock`，避免同时挖方块。

## 5. 数据与其它

- 罐子里的液体按背包存（背包数据可选字段 + 快照 + 降级拦截 + 协议号 19）；取下罐子液体留在背包里，装回去就回来；换成装不下现有液体的更小罐被拒绝。
- 原油的具体流体：锁定为第一次吸收的那种，直到排空。
- 面板里画液量条，悬停提示液体名与 mB。罐子受 `never_trash` 保护。
- 贴图：程序按"四档材质 × 五种液体"生成占位图，用户之后替换。
- 创造模式与生存一致。

## 6. 拆分

- **048**：罐子物品、背包档次放入规则、同液体互斥、数据与同步、面板液量显示、配方。
- **049**：水、原油、岩浆管的吸收与放置。
- **050**：牛奶、蜂蜜，以及五种管子的排放到容器。

## 8. 补充（2026-11-12，用户在 048 实现后提出）

1. **隐藏液体**（并入 048，US6）：背包里记着液体而底部区没有对应的罐，就算"隐藏内容"：标题栏黄点（037 已有）、悬停说明、`/hidden` 汇总里列出液体（"水（液体）：8000 mB"），提示"把对应的罐放进底部区就能继续使用"。判定在客户端，不新增网络包。
2. **原油的测试用 PneumaticCraft: Repressurized（PNC）**（049 的 plan 阶段落实）：
   - PNC 在 1.21.1 NeoForge 上有版本（Modrinth 与 CurseForge 都有，8.2.x）；它会在地表生成与水类似的石油，命令 `setblock ~ ~ ~ pneumaticcraft:oil` 可放置流体方块。
   - 依赖方式按宪法 VII：**只作为开发运行时的 `localRuntime`**（放进 `-PcompatRuntime` 那一组，不进发布的 jar、不写进 `neoforge.mods.toml`）；**不需要 `compileOnly`**——本模组只认流体标签 `#c:crude_oil`，不引用 PNC 的任何类型。只有 049 的 plan 查证后发现必须引用 PNC 的类型，才加 `compileOnly` 并把代码放进 `compat/pneumaticcraft/`。
   - **未验证（049 plan 第一步查证）**：PNC 的石油到底带不带 `c:crude_oil` 流体标签（搜索只确认 8.2.13 起把燃料流体标签改成了 `c:<流体名>`，没有直接看到 `crude_oil`）；PNC 版本与它的依赖（是否要 curios、jei 之外的库）；PNC 在容器里（arm64、软件渲染）能不能起来。
3. **牛奶与蜂蜜的测试不需要额外的模组**（050）：牛 `summon cow`、成年山羊 `summon goat`、蜂巢 `setblock ~ ~ ~ minecraft:beehive[honey_level=5]`（不带蜜蜂也行）、物品 `give @s milk_bucket / honey_bottle / bucket / glass_bottle`。
