宪法 V 条要求：玩家可见的行为必须在真实客户端会话里验证。各 feature 的 `quickstart.md` 有完整清单，
这份文件只保留**还没验证**的项；已验证的项已经记录在各自的 `specs/*/DELIVERY.md` 里。
判定标准以各 `quickstart.md` 为准。验证后把**编号和结果**告诉 Claude，由它写入 DELIVERY.md 并勾选任务。

**编号约定**：旧项沿用 `D3`、`J1`、`M1`、`K3`；新增项写成 `功能号-quickstart 条目号`，如 `012-21` 表示 `specs/012-*/quickstart.md` 第 21 条，`021-Q5` 表示 021 的 Q5。
**关于"HUD"**：019 之后"没开任何界面"指的是**透明宿主界面**（按 B 打开面板）；凡写"宿主 / 打开着界面各做一遍"，指宿主上一遍、按 E 或开着箱子再一遍。
**macOS**：quickstart 里的 Ctrl 都指 **Command**，Alt 指 **Option**。Windows/Linux 无法验证，不在清单里。

```bash
pgrep -f "fml.modFolders=mcfloatingbackpack" || echo "没有游戏在跑"   # 有就先退出，不要同时开两个
./gradlew runClient          # 会话 S1/S2 现在是同一套模组：JEI、精妙背包、旅行者背包、Curios、Accessories、Sodium + Iris（2026-11-09 合并；要干净环境加 -PcleanRuntime）
```

进一个**创造模式**世界。准备：五档背包各一只（创造分类或 JEI 搜 `floating backpack`）、标签管理器、垃圾桶、箱子、木桶、末影箱、潜影盒、漏斗、发射器、熔炉、工作台、铁砧、酿造台、一个村民；圆石若干（60、30、20 个等零散堆叠）、橡木原木、几种工具（一把磨损的钻石镐、一把附魔的、一把改了名的）、一个装了东西的潜影盒、一只别的浮动背包。
